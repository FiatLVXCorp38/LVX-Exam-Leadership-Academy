# LVX Exam & Leadership Academy

The repository root (`index.html`) is the original LVX starter-project public landing page. Visitors see this page first. The Enter Academy links open the learning center at `site/LVX_NY_Study_Hub/`. The learning center currently contains a static prototype; student-specific access restrictions, account authentication, payments, and server-side authorization must be implemented before paid or restricted course material is published.

Current academy launch focus: New York State County Corrections.
